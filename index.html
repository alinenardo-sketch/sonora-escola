Sobre o projeto

O SONORA é uma proposta tecnológica para observar os níveis de ruído em diferentes ambientes da escola e transformar essas informações em dados visuais de fácil compreensão.

O projeto relaciona tecnologia, Física, programação, acessibilidade e inclusão, permitindo identificar ambientes que apresentam maior intensidade sonora e pensar em estratégias para melhorar o conforto acústico escolar.

⚠️ Importante: Os valores apresentados inicialmente no painel são dados simulados, utilizados para demonstrar o funcionamento da plataforma. O sensor KY-037 utilizado no protótipo eletrônico fornece uma leitura relativa da intensidade sonora. Ele não deve ser tratado, sem calibração adequada, como um medidor profissional de decibéis.

🔌 Protótipo eletrônico

🚦 Semáforo Sonoro — Arduino + KY-037

O protótipo eletrônico desenvolvido no Cirkit Designer utiliza um Arduino Uno, um sensor de som KY-037 e três LEDs para representar diferentes níveis de intensidade sonora.

A lógica utilizada é simples:

🟢 Verde: som baixo
🟡 Amarelo: som intermediário
🔴 Vermelho: som elevado

♿ Acessibilidade e TEA

Algumas pessoas com Transtorno do Espectro Autista (TEA) podem apresentar maior sensibilidade a estímulos sonoros. Essa característica varia de pessoa para pessoa.

Por isso, o monitoramento do ambiente pode contribuir para identificar situações de desconforto e apoiar estratégias de organização dos espaços escolares.

🔊 Ambiente sonoro

Identificar locais e horários em que ocorre maior intensidade sonora.

🧩 Inclusão

Considerar diferentes necessidades sensoriais presentes no ambiente escolar.

📊 Dados

Transformar observações em informações visuais para apoiar decisões pedagógicas.

💡 Estratégias de melhoria

🔇 Redução de ruído

Avaliar organização das atividades, circulação de pessoas e fontes de ruído.

🏫 Organização do espaço

Identificar ambientes que podem precisar de estratégias específicas de organização.

🧠 Conforto sensorial

Considerar alternativas para estudantes que apresentam maior sensibilidade aos estímulos sonoros.

📚 Base científica do projeto

O projeto utiliza conceitos de Física relacionados às ondas sonoras, intensidade sonora, propagação do som e percepção auditiva.

Também integra conceitos de programação, Internet, visualização de dados, tecnologia educacional, acessibilidade e inclusão.

A classificação apresentada pelo semáforo deve ser entendida como uma estratégia visual do projeto e não como diagnóstico médico ou avaliação clínica.
