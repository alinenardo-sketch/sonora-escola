O sensor KY-037 utilizado no protótipo eletrônico fornece uma leitura relativa de intensidade sonora e não deve ser considerado, sem calibração e metodologia adequada, um medidor profissional de decibéis (dB).

🔌 Protótipo eletrônico

Como funciona?

O protótipo eletrônico utiliza um Arduino Uno conectado a um sensor KY-037. O sensor realiza uma leitura relativa da intensidade sonora e o Arduino utiliza essa informação para acionar um dos três LEDs.


🟢 Verde → som baixo

🟡 Amarelo → som intermediário

🔴 Vermelho → som elevado


🔗 Abrir protótipo no Cirkit Designer

Componentes utilizados

🔧 Arduino Uno
🎤 Sensor de som KY-037
🟢 LED verde
🟡 LED amarelo
🔴 LED vermelho
⚡ Resistores de 200 Ω

🧪 Metodologia de coleta

A metodologia do SONORA foi organizada para permitir o registro sistemático das condições sonoras em diferentes ambientes e momentos da rotina escolar.


1

Definição dos ambientes

Foram considerados diferentes espaços da escola: biblioteca, sala de aula, corredor, refeitório, pátio e quadra.

2

Definição dos períodos

Os registros podem ser realizados em diferentes momentos: manhã, intervalo, almoço e período da tarde.

3

Registro da atividade

O aluno registra o que estava acontecendo no ambiente: aula, circulação, alimentação, intervalo ou atividade física.

4

Observação do contexto

Além do valor observado, podem ser registradas fontes de ruído, movimentação de pessoas, portas, atividades coletivas e outras características do ambiente.

5

Classificação visual

Os registros são apresentados por meio do sistema visual verde, amarelo e vermelho para facilitar a interpretação.

6

Análise dos dados

Os dados podem ser analisados por ambiente, período, horário e atividade para identificar padrões.

Limitação do protótipo: o KY-037 fornece uma leitura relativa de intensidade sonora. Os valores apresentados no sistema não representam automaticamente medições reais em decibéis. Para medições quantitativas em dB, seria necessário equipamento apropriado e metodologia de calibração.

♿ Acessibilidade e inclusão

Por que observar o som?

O ambiente sonoro faz parte das condições de aprendizagem e convivência escolar. A observação dos níveis sonoros pode ajudar a escola a identificar situações que mereçam atenção.


Algumas pessoas com Transtorno do Espectro Autista (TEA) podem apresentar maior sensibilidade a estímulos sonoros. Essa característica varia de pessoa para pessoa.

O que podemos fazer?

  • Identificar ambientes mais ruidosos.
  • Observar os horários de maior movimentação.
  • Discutir estratégias para reduzir ruídos desnecessários.
  • Considerar diferentes necessidades sensoriais.
  • Promover ambientes escolares mais acolhedores.
  • Utilizar dados para apoiar decisões pedagógicas.

💡 Estratégias de intervenção

🔇 Redução de ruídos

Identificar fontes de ruído desnecessárias e discutir alternativas para diminuir sua intensidade.

🕐 Organização dos horários

Observar os momentos de maior movimentação para planejar estratégias específicas.

🧠 Consciência sensorial

Promover discussões sobre como diferentes estímulos podem ser percebidos pelas pessoas.

📊 Uso dos dados

Utilizar os registros para apoiar decisões e propostas de melhoria do ambiente escolar.

⚙️ Controle dos dados

Os registros realizados neste dispositivo podem ser apagados para iniciar uma nova coleta de dados.
